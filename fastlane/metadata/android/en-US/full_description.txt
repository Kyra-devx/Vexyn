Vexyn is a community-maintained code editor and web IDE for Android, based on the Acode codebase. It is intended for editing source files and working on web projects from a phone or tablet.

CODE EDITING

- Syntax highlighting for many programming languages
- Multi-file editing with tabs
- Code completion and language intelligence through supported plugins
- Keyboard shortcuts and Emmet support
- Customizable themes and fonts
- Search across project files

WEB DEVELOPMENT

- Edit HTML, CSS, JavaScript and other source files
- Preview supported HTML and Markdown content
- Use the built-in JavaScript console
- Extend workflows with community plugins and formatters

TERMINAL AND REMOTE WORK

- Built-in Alpine Linux terminal powered by proot, where supported
- Git workflows and branch management
- SSH, FTP and SFTP integrations
- Plugin support for additional language servers and tools

COMMUNITY FORK

Vexyn is an independent community fork and is not the official Acode app. The codebase retains upstream components and attribution under their applicable licenses. Vexyn distribution channels and release signing are not yet established; do not treat upstream Acode store packages as Vexyn releases.

GETTING STARTED

Build from the Vexyn source repository using CONTRIBUTING.md. Verify build output and test on a device before distributing an APK.
